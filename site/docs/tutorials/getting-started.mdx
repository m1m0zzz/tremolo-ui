## 🧬Install @tremolo-ui/react

1. Install tremolo-ui

```bash npm2yarn
npm install @tremolo-ui/react
```

2. Install dependencies

```bash npm2yarn
npm install react react-dom
```

3. Import the components you need.

```jsx title="index.tsx"
import { Knob } from '@tremolo-ui/react'
```

tremolo-ui ships no CSS: a component renders its markup and leaves the
appearance to you. [Styling](./styling.mdx) covers how to give it one, and
publishes the theme these examples use so you can start from it.
