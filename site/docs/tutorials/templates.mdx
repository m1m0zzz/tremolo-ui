# Start from a template

The templates live in [the tremolo-ui repository](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates),
next to the packages, and are built on every change — so they always use the
current API. Copy one out with [degit](https://github.com/Rich-Harris/degit),
which takes the files without the history.

Each one shows every component wired up to
[the theme these docs use](/docs/tutorials/styling#the-theme-used-on-this-site),
copied into `src/theme/`. tremolo-ui ships no CSS, so those files are yours to
edit.

## vite-react-ts

Vite, React and TypeScript, linted with Oxlint.

```bash
npx degit m1m0zzz/tremolo-ui/templates/vite-react-ts my-app
cd my-app
npm install
npm run dev
```

[Source](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates/vite-react-ts)

## next-ts

Next.js (App Router) and TypeScript, linted with ESLint.

```bash
npx degit m1m0zzz/tremolo-ui/templates/next-ts my-app
cd my-app
npm install
npm run dev
```

[Source](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates/next-ts)
