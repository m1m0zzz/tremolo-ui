## API Reference {#api-reference}

`Piano.Root` also takes the attributes of the element it renders, such as
`className` and `style`.

State is on the element as a data attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its state
is on.

### Root

Draws a key for every note in `noteRange`. It has no other parts: a key is
customised through `label` and `keyProps`.

<PropsTable of="PianoProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-resizable` | `"true"` | Present while `resizable` is set. |

#### Keys

Each key carries these.

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-note` | `"0"` … `"127"` | The note number of the key, e.g. `"60"`. Always present. |
| `data-note-key` | `"C" \| "C#" \| … \| "B"` | The pitch class of the key. Always present. |
| `data-active` | `"true"` | Present while the note is sounding. |
| `data-disabled` | `"true"` | Present when the note is past `midiMax`. |

A key takes more through `keyProps`, so a state of your own is one more
attribute:

```jsx
keyProps={(note) => ({ 'data-in-scale': inScale(note, 0, 'major') || undefined })}
```
