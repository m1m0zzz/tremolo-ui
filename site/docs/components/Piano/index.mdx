## Data attributes

State is on the element as an attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its
state is on.

| Attribute | Part | Present when |
| --- | --- | --- |
| `data-fill` | `Piano.Root` | `fill` is set |
| `data-note` | each key | always; the note number of the key, e.g. `60` |
| `data-note-key` | each key | always; the pitch class of the key, `C`, `C#` … `B` |
| `data-active` | each key | the note is sounding |
| `data-disabled` | each key | the note is past the highest MIDI note |

A key takes more through `keyProps`, so a state of your own is one more
attribute:

```jsx
keyProps={(note) => ({ 'data-in-scale': inScale(note, 0, 'major') || undefined })}
```
