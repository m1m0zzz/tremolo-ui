# PointsEditor

Editor for a set of points, each one dragged within the same area.

A point is placed by its position in the container, so its value is `{ x, y }`
in the range 0..1 on each axis, with `y` growing downwards. Points can be
selected and moved together, with ctrl / meta or by dragging a
`<PointsEditor.SelectionBox />` over them.


## Data attributes

State is on the element as an attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its
state is on.

| Attribute | Part | Present when |
| --- | --- | --- |
| `data-disabled` | `PointsEditor.Root`, `PointsEditor.Point` | `disabled` is set |
| `data-readonly` | `PointsEditor.Root`, `PointsEditor.Point` | `readonly` is set |
| `data-dragging` | `PointsEditor.Point` | the point is being dragged |
| `data-selected` | `PointsEditor.Point` | the point is in the selection |

## Examples

### Basic

Drag a point, or click one and use the arrow keys. The wheel moves the focused
point from anywhere over the editor, and shift switches it to the x axis.
