# PointsEditor

Editor for a set of points, each one dragged within the same area.

A point is placed by its position in the container, so its value is `{ x, y }`
in the range 0..1 on each axis, with `y` growing downwards. Points can be
selected and moved together, with ctrl / meta or by dragging a
`<PointsEditor.SelectionBox />` over them.

Drag a point, or click one and use the arrow keys. The wheel moves the focused
point from anywhere over the editor, and shift switches it to the x axis.

## API Reference {#api-reference}

Each part lists the props of its own. It also takes the attributes of the
element it renders, such as `className` and `style`.

In Svelte the props are the same, written the Svelte way — `class` rather
than `className`, `bind:value`, snippets for content. See
[Svelte](/docs/tutorials/svelte).

State is on the element as a data attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its state
is on.

### Root

Holds the selection and the settings every point shares.

<PropsTable of="PointsEditorProps" />

Set the editor's width and height with CSS or `style`.

| Data attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled` is set |
| `[data-readonly]` | Present when `readonly` is set |

### Background

Drawn behind the points. Whatever they are placed over goes inside it: a
graph, a canvas, an image.

It has no props of its own and takes the attributes of a `<div>`.

### Container

The area the points are placed in. A drag on its empty space draws a
selection. `PointsEditor.Point` goes inside it.

It has no props of its own and takes the attributes of a `<div>`.

### Point

One point, moved by dragging, the arrow keys or the wheel. Two visually hidden
range inputs inside it, one per axis, take the focus and carry the ARIA.
Children are drawn inside the point; the theme's own dot stands when there are
none.

<PropsTable of="PointsEditorPointProps" />

| Custom property | Written by | What it sets |
| --- | --- | --- |
| `--color` | `color` | Colour of the point. |

Set a point's width and height with CSS or `style`.

| Data attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled` is set, on the point or on `Root` |
| `[data-readonly]` | Present when `readonly` is set, on the point or on `Root` |
| `[data-dragging]` | Present while the point is being dragged |
| `[data-selected]` | Present while the point is in the selection |

### SelectionBox

The box a drag on empty space draws; the points it covers are selected. Nothing
is rendered while no drag is running, children included.

It has no props of its own and takes the attributes of a `<div>`.
