## API Reference {#api-reference}

Each part lists the props of its own. It also takes the attributes of the
element it renders, such as `className` and `style`.

State is on the element as a data attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its state
is on.

### Root

Holds the value and the settings, and passes them to the parts inside.

<PropsTable of="SliderProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-orientation` | `"horizontal" \| "vertical"` | Which way the slider runs. |
| `data-disabled` | `"true"` | Present while `disabled` is set. |
| `data-readonly` | `"true"` | Present while `readonly` is set. |

### Track

The bar the value runs along. It sets `--percent` to where the value is, so
the theme can fill the part below it.

<PropsTable of="SliderTrackProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-orientation` | `"horizontal" \| "vertical"` | Which way the slider runs. |
| `data-disabled` | `"true"` | Present while `disabled` is set. |
| `data-flipped` | `"true"` | Present while the value grows from the far end: `vertical` or `reverse`, but not both. |

### Thumb

The handle. A visually hidden range input inside it takes the focus and
carries the ARIA.

<PropsTable of="SliderThumbProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-disabled` | `"true"` | Present while `disabled` is set. |
| `data-readonly` | `"true"` | Present while `readonly` is set. |

### Marks

A row of marks along the track, built from `options` or from
`Slider.MarksOption` children.

<PropsTable of="SliderMarksProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-orientation` | `"horizontal" \| "vertical"` | Which way the slider runs. |

### MarksOption

One mark and its label, placed at `value`.

<PropsTable of="SliderMarksOptionProps" />

| Data attribute | Values | Description |
| --- | --- | --- |
| `data-orientation` | `"horizontal" \| "vertical"` | Which way the slider runs. The mark inside carries it too. |
