## API Reference {#api-reference}

Each part lists the props of its own. It also takes the attributes of the
element it renders, such as `className` and `style`.

State is on the element as a data attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its state
is on.

### Root

Holds the value of both axes and the settings, and passes them to the parts
inside.

<PropsTable of="XYPadProps" />

| Data attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled` is set |
| `[data-readonly]` | Present when `readonly` is set |

### Area

The surface the thumb moves across. `XYPad.Thumb` goes inside it.

<PropsTable of="XYPadAreaProps" />

| Custom property | Written by | What it sets |
| --- | --- | --- |
| `--width` | `width` | Width of the area. |
| `--height` | `height` | Height of the area. |
| `--color` | `color` | Colour of the area. |

### Thumb

The handle. Two visually hidden range inputs inside it, one per axis, take the
focus and carry the ARIA.

Its children are drawn inside it. The thumb is one element either way, so what
is passed there is decoration on top of it rather than a replacement for it —
`className` and `style` are how its own appearance is changed.

<PropsTable of="XYPadThumbProps" />

| Custom property | Written by | What it sets |
| --- | --- | --- |
| `--color` | `color` | Colour of the thumb. |

| Data attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled` is set |
| `[data-readonly]` | Present when `readonly` is set |
