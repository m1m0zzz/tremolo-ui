## API Reference {#api-reference}

Each part lists the props of its own. It also takes the attributes of the
element it renders, such as `className` and `style`.

In Svelte and Vue the props are the same, written their way — `class` rather
than `className`, `bind:value` or `v-model`, snippets or slots for content. See
[Svelte](/docs/tutorials/svelte) and [Vue](/docs/tutorials/vue).

State is on the element as a data attribute, so it is a selector away — see
[Styling](/docs/tutorials/styling). An attribute is only there while its state
is on.

### Root

Holds the value and handles the drag, the wheel and the arrow keys. It is the
control itself: it takes the focus and carries the ARIA.

<PropsTable of="KnobProps" />

| Custom property | Written by | What it sets |
| --- | --- | --- |
| `--knob-size` | `size` | The width and height of the knob. |

| Data attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled` is set |
| `[data-readonly]` | Present when `readonly` is set |
| `[data-dragging]` | Present while a drag is in progress |

### SVGRoot

The `<svg>` the drawing parts go in. It sets the view box they are drawn
against.

<PropsTable of="KnobSVGRootProps" />

### InactiveLine

The arc outside the value. It has no props of its own and takes the attributes
of an SVG `<path>`. The arc is kept inside the view box by the `strokeWidth`
you give it.

### ActiveLine

The arc between `startValue` and the value. Like `Knob.InactiveLine`, it takes
the attributes of an SVG `<path>`.

### Thumb

The circle that turns with the value, and the line on it that points at the
value.
