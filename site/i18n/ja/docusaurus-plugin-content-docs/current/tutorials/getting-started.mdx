## Install @tremolo-ui/react

Svelte を使う場合は、代わりに `@tremolo-ui/svelte` をインストールします（[Svelte](/docs/tutorials/svelte) を参照）。

1. tremolo-uiをインストールします

```bash npm2yarn
npm install @tremolo-ui/react
```

2. 依存関係をインストールします

```bash npm2yarn
npm install react react-dom
```

3. 必要なコンポーネントをインポートします。

```jsx title="index.tsx"
import { Knob } from '@tremolo-ui/react'
```

`@tremolo-ui/react` が公開するのはコンポーネントと hooks だけです。スケールや
MIDI のノート名などの関数は `@tremolo-ui/functions` に、他のフレームワークと共通の
値や型（`XY`、入力の既定値、MIDI のエラーコードなど）は `@tremolo-ui/dom` にあります。
これらから import するときは、依存に追加してください。

```bash npm2yarn
npm install @tremolo-ui/functions @tremolo-ui/dom
```

tremolo-ui は CSS を配りません。コンポーネントはマークアップだけを描画し、
見た目は利用者に委ねます。[Styling](/docs/tutorials/styling) にスタイルの当て方と、
このドキュメントの例で使っているテーマを載せてあります。
