# テンプレートから始める

テンプレートは [tremolo-ui のリポジトリ](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates)
にパッケージと一緒に置いてあり、変更のたびにビルドしています。いつでも最新の API で
書かれています。履歴を含めずにファイルだけを取り出せる
[degit](https://github.com/Rich-Harris/degit) でコピーしてください。

どのテンプレートも、全コンポーネントに
[このドキュメントで使っているテーマ](/docs/tutorials/styling#このサイトで使っているテーマ)
を当てた例になっています。テーマは `src/theme/` にコピーしてあります。tremolo-ui は
CSS を配らないので、これらのファイルは自由に書き換えてください。

## vite-react-ts

Vite + React + TypeScript。lint は Oxlint です。

```bash
npx degit m1m0zzz/tremolo-ui/templates/vite-react-ts my-app
cd my-app
npm install
npm run dev
```

[ソースコード](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates/vite-react-ts)

## next-ts

Next.js (App Router) + TypeScript。lint は ESLint です。

```bash
npx degit m1m0zzz/tremolo-ui/templates/next-ts my-app
cd my-app
npm install
npm run dev
```

[ソースコード](https://github.com/m1m0zzz/tremolo-ui/tree/main/templates/next-ts)
