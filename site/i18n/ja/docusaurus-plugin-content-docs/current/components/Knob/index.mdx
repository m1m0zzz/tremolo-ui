## API リファレンス {#api-reference}

各パートには、そのパート独自の props を載せています。これに加えて、描画する要素の属性（`className` や `style` など）も受け取ります。

Svelte でも props は同じで、書き方だけが Svelte 流になります（`className` ではなく `class`、`bind:value`、中身は snippet など）。[Svelte](/docs/tutorials/svelte) を参照してください。

状態は data 属性として要素に乗っているので、セレクタ 1 つで届きます（[スタイリング](/docs/tutorials/styling)を参照）。属性はその状態が on の間だけ付きます。

### Root

値を持ち、ドラッグ・ホイール・矢印キーを処理します。これ自体がコントロールで、フォーカスを受け取り ARIA を持ちます。

<PropsTable of="KnobProps" />

| カスタムプロパティ | 書き込む prop | 決めるもの |
| --- | --- | --- |
| `--knob-size` | `size` | ノブの幅と高さ。 |

| Data 属性 | 値 |
| --- | --- |
| `[data-disabled]` | `disabled` のときに付きます |
| `[data-readonly]` | `readonly` のときに付きます |
| `[data-dragging]` | ドラッグしている間に付きます |

### SVGRoot

描画用のパートを入れる `<svg>`。パートが描く基準になる viewBox を設定します。

<PropsTable of="KnobSVGRootProps" />

### InactiveLine

値の外側の円弧。独自の props は無く、SVG の `<path>` の属性を受け取ります。円弧は、渡した `strokeWidth` の分だけ内側に描かれ、viewBox に収まります。

### ActiveLine

`startValue` と値の間の円弧。`Knob.InactiveLine` と同じく、SVG の `<path>` の属性を受け取ります。

### Thumb

値に合わせて回る円と、その上で値を指す線。
