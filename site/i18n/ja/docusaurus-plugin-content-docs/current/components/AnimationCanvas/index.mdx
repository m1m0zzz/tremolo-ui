## 特長 {#features}

- [devicePixelRatio](https://developer.mozilla.org/docs/Web/API/Window/devicePixelRatio) に合わせます。
- リサイズしたときのちらつきを抑えます。
- 親要素の大きさを監視します。
- シンプルなティッカーとタイマー

### Fixed と Resizable {#fixed-vs-resizable}

キャンバスは既定で固定サイズで、`width` と `height` が CSS ピクセルでの大きさを決めます。`resizable` を付けると、代わりに親要素の大きさに合わせるので、親要素が自分の大きさを持っている必要があります。2 つは排他的で、`resizable` と一緒に `width` や `height` を渡すと型エラーになります。

### Reactive Canvas {#reactive-canvas}

既定では、キャンバスはアニメーションフレームごとに描き直します。描画が時間ではなく state で決まるときは `animate={false}` にします。するとキャンバスは、描く理由があるときだけ描きます。マウントしたとき、リサイズされたとき、そして**コンポーネントが再レンダーされたとき**です。

最後の 1 つがあるので、`React.useState` をそのまま描画の元にできます。新しい `draw` を渡せばキャンバスが描き直すので、メモ化するものも、手で起こす再描画もありません。

動く例は下の [Reactive](#reactive) にあります。

:::tip

どちらの場合でも、`draw` はインラインで書いて構いません。キャンバスは 1 度だけ作られ、ハンドラはその場で差し替えられるので、再レンダーでアニメーションが最初からやり直しになったり、`count` や `elapsedTime` がリセットされたり、`init` がもう 1 度走ったりはしません。コンポーネントを `React.memo` で包んだり、`draw` を `useCallback` で持ったりする必要はありません。

:::
