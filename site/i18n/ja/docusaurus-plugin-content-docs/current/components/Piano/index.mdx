## API リファレンス {#api-reference}

`Piano.Root` は、下の props に加えて、描画する要素の属性（`className` や `style` など）も受け取ります。

Svelte / Vue でも props は同じで、書き方だけがそれぞれの流儀になります（`className` ではなく `class`、`bind:value` や `v-model`、中身は snippet やスロットなど）。[Svelte](/docs/tutorials/svelte) と [Vue](/docs/tutorials/vue) を参照してください。

状態は data 属性として要素に乗っているので、セレクタ 1 つで届きます（[スタイリング](/docs/tutorials/styling)を参照）。属性はその状態が on の間だけ付きます。

### Root

`noteRange` のノートごとに鍵盤を描きます。他のパートは無く、鍵盤は `label` と `keyProps` でカスタマイズします。

<PropsTable of="PianoProps" />

鍵盤の高さと各キーの色は CSS で指定します。キーごとにクラス、スタイル、
`data-*` 属性を付けるには `keyProps` を使います。

| Data 属性 | 値 |
| --- | --- |
| `[data-resizable]` | `resizable` のときに付きます |

#### 鍵盤 {#keys}

各鍵盤が持つ属性です。

| Data 属性 | 値 |
| --- | --- |
| `[data-note]` | `"0"` … `"127"` |
| `[data-note-key]` | `"C" \| "C#" \| … \| "B"` |
| `[data-active]` | ノートが鳴っている間に付きます |
| `[data-disabled]` | ノートが `midiMax` より高いときに付きます |

鍵盤には `keyProps` から属性を足せるので、自分で決めた状態も属性 1 つで表せます:

```jsx
keyProps={(note) => ({ 'data-in-scale': inScale(note, 0, 'major') ? '' : undefined })}
```
