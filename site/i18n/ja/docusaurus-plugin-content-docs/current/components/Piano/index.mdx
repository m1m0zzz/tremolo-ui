## API リファレンス {#api-reference}

`Piano.Root` は、下の props に加えて、描画する要素の属性（`className` や `style` など）も受け取ります。

状態は data 属性として要素に乗っているので、セレクタ 1 つで届きます（[スタイリング](/docs/tutorials/styling)を参照）。属性はその状態が on の間だけ付きます。

### Root

`noteRange` のノートごとに鍵盤を描きます。他のパートは無く、鍵盤は `label` と `keyProps` でカスタマイズします。

<PropsTable of="PianoProps" />

| カスタムプロパティ | 書き込む prop | 決めるもの |
| --- | --- | --- |
| `--height` | `height` | 鍵盤の高さ。 |

鍵盤の色はテーマ側の取り決めです。[スタイリング](/docs/tutorials/styling)のページに
あるテーマは鍵盤の種類ごとに変数を持っていて、鍵盤には `keyProps` から渡したものが
そのまま付きます。

| Data 属性 | 値 | 説明 |
| --- | --- | --- |
| `data-resizable` | `"true"` | `resizable` を設定している間だけ付きます。 |

#### 鍵盤 {#keys}

各鍵盤が持つ属性です。

| Data 属性 | 値 | 説明 |
| --- | --- | --- |
| `data-note` | `"0"` … `"127"` | 鍵盤のノート番号（例: `"60"`）。常に付きます。 |
| `data-note-key` | `"C" \| "C#" \| … \| "B"` | 鍵盤の音名。常に付きます。 |
| `data-active` | `"true"` | ノートが鳴っている間だけ付きます。 |
| `data-disabled` | `"true"` | ノートが `midiMax` より高いときに付きます。 |

鍵盤には `keyProps` から属性を足せるので、自分で決めた状態も属性 1 つで表せます:

```jsx
keyProps={(note) => ({ 'data-in-scale': inScale(note, 0, 'major') || undefined })}
```
